# 0.4.0 — 2026-10-15

## Added

- **`paleobiology_get_references`** resolves `reference_no` values from occurrence and collection rows to full citations in one PBDB request, listing misses in `not_found` and any ids past the first 25 distinct in `remaining_reference_nos` ([#25](https://github.com/cyanheads/paleobiology-mcp-server/issues/25)).
- **`paleobiology://reference/{reference_no}`** resource returns one reference ([#25](https://github.com/cyanheads/paleobiology-mcp-server/issues/25)).
- **`conflicting_selector`** on `paleobiology_get_taxon` and **`inverted_ma_range`** on `paleobiology_list_intervals` reject contradictory inputs that previously read as not-found or matched nothing ([#22](https://github.com/cyanheads/paleobiology-mcp-server/issues/22)).
- **`pbdb_invalid_parameter`** is declared on the occurrence, collection, and diversity searches, with a recovery hint ([#24](https://github.com/cyanheads/paleobiology-mcp-server/issues/24)).

## Changed

- **`paleobiology_search_occurrences`, `paleobiology_search_collections`, and `paleobiology_dataframe_query`** cut rows at a whole row to keep each response surface within 100,000 bytes, with a notice naming the next `offset` or the `LIMIT`/`OFFSET` that reads the rest; `limit` above 500 is served at 500 instead of rejected, up to 10,000 ([#23](https://github.com/cyanheads/paleobiology-mcp-server/issues/23)).
- **`paleobiology_dataframe_query`** counts `row_count` up to the canvas row cap, and `truncated: true` means counting stopped there ([#23](https://github.com/cyanheads/paleobiology-mcp-server/issues/23)).
- **Blank optional inputs** (`""` or whitespace) count as unset across the search, taxon, diversity, and interval tools, including enums and `canvas_id` ([#22](https://github.com/cyanheads/paleobiology-mcp-server/issues/22)).
- **`paleobiology_search_occurrences`** names `paleobiology_dataframe_describe` before `paleobiology_dataframe_query` in its spill notice and in the `canvas_id`, `table_name`, and tool descriptions ([#26](https://github.com/cyanheads/paleobiology-mcp-server/issues/26)).
- **`paleobiology_dataframe_query`, `paleobiology_dataframe_describe`, and `paleobiology_dataframe_drop`** are listed in `tools/list` only when DataCanvas is on (`CANVAS_PROVIDER_TYPE=duckdb`); the drop tool also needs `PALEOBIOLOGY_DATAFRAME_DROP_ENABLED=true` ([#27](https://github.com/cyanheads/paleobiology-mcp-server/issues/27)).
- **`paleobiology_dataframe_drop`** reports `canvas_not_found` for an expired or unknown `canvas_id`, with recovery that fits a drop ([#27](https://github.com/cyanheads/paleobiology-mcp-server/issues/27)).
- **Server config** is parsed in `setup()`, so an invalid `PBDB_*` value fails startup behind the banner.
- **Container, bundle, and docs** move to Bun 1.4.3 images, exclude `.cache/`, `tests/`, `src/`, `scripts/`, `docs/`, and similar from the `.mcpb` ([#31](https://github.com/cyanheads/paleobiology-mcp-server/issues/31)), and sync framework skills and guidance.

## Fixed

- **PBDB rejection messages** lead with PBDB's `warnings[]`, which name the unusable value (an unknown interval or lithology), ahead of `errors[]` ([#24](https://github.com/cyanheads/paleobiology-mcp-server/issues/24)).
- **`paleobiology_search_collections`** renders an exhausted page (`offset` past the total) as a page past the end, not as no match ([#24](https://github.com/cyanheads/paleobiology-mcp-server/issues/24)).
- **`paleobiology_search_occurrences`** acquires a canvas only when a page spills, so inline results, empty results, and upstream errors no longer hold a canvas slot, and a caller's `canvas_id` is left untouched ([#32](https://github.com/cyanheads/paleobiology-mcp-server/issues/32)).
- **Rendered `content[]` text** flattens line breaks in PBDB-supplied names, strata, and localities so they cannot start new lines ([#33](https://github.com/cyanheads/paleobiology-mcp-server/issues/33)).
- **Collection text fields** strip wrapping double quotes only as a matched pair, so a lithology description opening with a quoted phrase keeps its quotes ([#34](https://github.com/cyanheads/paleobiology-mcp-server/issues/34)).
- **`canvas_capacity_exhausted`** on a spilling `paleobiology_search_occurrences` names levers that work here: pass a held `canvas_id`, or lower `limit` ([#35](https://github.com/cyanheads/paleobiology-mcp-server/issues/35)).
