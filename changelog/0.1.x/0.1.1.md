# 0.1.1 — 2026-06-25

Initial release. Fossil biodiversity over the Paleobiology Database (PBDB, `paleobiodb.org/data1.2`) — keyless, CC BY 4.0.

## Added

- **`paleobiology_search_occurrences`** — search fossil occurrences by taxon, geologic time, geography, and depositional environment; every row carries both modern and paleo coordinates. Broad results spill to a DataCanvas for SQL.
- **`paleobiology_get_taxon`** — resolve a taxon by name or `taxon_no` to its accepted name, rank, classification, parent, occurrence count, and FAD/LAD range. The name-resolution gateway for the other tools.
- **`paleobiology_get_diversity`** — origination / extinction / diversity curve for a clade across geologic time, binned by period, epoch, or age.
- **`paleobiology_search_collections`** — find fossil collections (localities) by area and geologic time, with formation, lithology, depositional environment, and co-occurring-fossils count.
- **`paleobiology_list_intervals`** — look up the geologic time scale and translate named intervals ↔ absolute Ma, served from a bundled ICS snapshot (no network call).
- **`paleobiology_dataframe_query`** / **`paleobiology_dataframe_describe`** — read-only SQL `SELECT` over occurrence sets staged on a DataCanvas, plus table/column discovery.
- **`paleobiology_dataframe_drop`** — drop a single staged table to free memory before its TTL expires. Opt-in via `PALEOBIOLOGY_DATAFRAME_DROP_ENABLED`.
- **Resources** `paleobiology://occurrence/{occurrence_no}` and `paleobiology://taxon/{taxon_no}` — single-record reads mirroring the occurrence and taxon tools.
- **Config** — `PBDB_BASE_URL`, `PBDB_TIMEOUT_MS`, `PBDB_MAX_OCCURRENCES`, `PALEOBIOLOGY_DATAFRAME_DROP_ENABLED`; DataCanvas spill enabled with `CANVAS_PROVIDER_TYPE=duckdb`.
- **STDIO and Streamable HTTP** transports, built on [`@cyanheads/mcp-ts-core`](https://www.npmjs.com/package/@cyanheads/mcp-ts-core).
