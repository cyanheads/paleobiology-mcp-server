# 0.5.0 — 2026-11-01

## Added

- Serve the paleobiology-guide skill through MCP resources and packaged distributions.
- **Search filters** add country and formation to occurrences, country to collections, and geographic, formation, and environment selectors to diversity; country codes normalize case and whitespace while preserving PBDB exclusion/subtraction syntax. ([#39](https://github.com/cyanheads/paleobiology-mcp-server/issues/39))
- **`recent`** optionally extends known extant taxa to the present in diversity series; the default remains fossil-only, with selected-set turnover and boundary effects disclosed. ([#38](https://github.com/cyanheads/paleobiology-mcp-server/issues/38))

## Changed

- **Occurrence analysis** defaults DataCanvas on; set `CANVAS_PROVIDER_TYPE=none` to disable it. The portable MCPB keeps canvas disabled because platform-specific DuckDB bindings are excluded.
- **Served pages** retain every fetched row, accept search limits through 10,000 subject to `PBDB_MAX_OCCURRENCES`, and resolve 500 distinct references per call. First occurrence pages with further matches stage up to 50,000 rows, disclose coverage, and preserve committed tables on failed replacements; later pages leave the canvas untouched. ([#40](https://github.com/cyanheads/paleobiology-mcp-server/issues/40))
- **SQL column qualification** is required for a staged column named `current_schema`: use `c.current_schema` with a table alias. Adopted framework validation rejects the previously accepted unqualified column reference.
- **Packaging** adds the Agent Plugins root manifests and excludes developer files and dependency build output from MCPB bundles while retaining executable SDK skill modules.

## Fixed

- **Taxon identity** keeps matched names, ranks, counts, parents, and ranges separate from accepted identifiers, names, ranks, and status; child nomina dubia are no longer mislabeled as synonyms. Use `accepted_no` for accepted-clade searches. ([#37](https://github.com/cyanheads/paleobiology-mcp-server/issues/37))
- **Classification** omits unspecified-rank markers across tools, resources, and staged JSON. ([#41](https://github.com/cyanheads/paleobiology-mcp-server/issues/41))
- **References** convert citation, title, and publication HTML to text with one entity decode and preserve literal text and line breaks. ([#42](https://github.com/cyanheads/paleobiology-mcp-server/issues/42))
- **Interval windows** require positive-duration overlap; explicit equal-bound points retain inclusive boundary matches. ([#43](https://github.com/cyanheads/paleobiology-mcp-server/issues/43))
