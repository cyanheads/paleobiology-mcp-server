# 0.3.0 — 2026-06-28

## Added

- **`collection_no`** — `paleobiology_search_occurrences` takes an optional `collection_no` (PBDB `coll_id`) to scope a search to one locality, completing the documented `paleobiology_search_collections` → occurrence drilldown. ([#5](https://github.com/cyanheads/paleobiology-mcp-server/issues/5))

## Fixed

- **Canvas spill cap disclosure** — `paleobiology_search_occurrences` no longer presents a capped page as the full set. When the PBDB pull fills the per-call cap (`limit`, bounded by `PBDB_MAX_OCCURRENCES`), the notice, `format()` header, and the `occurrences`/`row_count` output descriptions disclose that more may match upstream and how to retrieve the rest. ([#6](https://github.com/cyanheads/paleobiology-mcp-server/issues/6))
- **Filterless search rejection** — `paleobiology_search_occurrences` and `paleobiology_search_collections` reject a call carrying only pagination fields with a typed `missing_filter` (`InvalidParams`) error and recovery guidance, instead of forwarding the request and surfacing PBDB's rejection as a generic "unavailable" failure. ([#8](https://github.com/cyanheads/paleobiology-mcp-server/issues/8))
