# 0.3.7 — 2026-10-03

## Changed

- **Framework error handling** fills declared recovery hints and returns request IDs, distinguishes SQL failures, repairs supported argument shapes, and identifies output-contract failures as internal errors.
- **Framework logging and storage** honor the log-level floor and sensitive-field masking on client notifications, support opt-in OTLP log export and failed-call payload logging, and round-trip stored values as JSON.
- **Container builds** cross-install production dependencies on the build platform, install OpenTelemetry peers at framework-declared ranges, and remove musl bindings from the glibc image.
- **Development tooling and docs** synchronize framework skills, packaging checks, environment-file exclusions, and CodeQL language categories; clarify configuration and disabled-tool behavior.

## Fixed

- **`paleobiology_search_occurrences`** stages explicit column types, preserving fractional ages and coordinates plus fields first populated beyond the preview; absent optional values remain SQL NULL ([#29](https://github.com/cyanheads/paleobiology-mcp-server/issues/29)).
- **MCP Registry launch metadata** uses `npx` without npm-script arguments and fixes `MCP_TRANSPORT_TYPE=http` for the HTTP entry.
- **npm package contents** exclude the built MCPB bundle.
