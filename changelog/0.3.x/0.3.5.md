# 0.3.5 — 2026-08-24

Framework maintenance. No PBDB query behavior changed; the client-visible changes below arrive with `@cyanheads/mcp-ts-core` `^0.12.3`.

## Changed

- **`@cyanheads/mcp-ts-core` `^0.11.0` → `^0.12.3`**, crossing the framework's MCP SDK v2 migration. Every HTTP endpoint now serves protocol revision `2026-07-28` alongside the 2025 revisions it already negotiated, and advertised schemas are JSON Schema 2020-12 rather than draft-07.
- **Tool arguments are strict.** A root-level key that a `paleobiology_*` tool does not declare is rejected by name instead of silently stripped, and each `inputSchema` advertises `additionalProperties: false`.
- **The advertised `outputSchema` declares the error envelope.** Success fields are optional and `error` is declared, so a client that validates `structuredContent` without first checking `isError` no longer rejects a typed failure such as `taxon_not_found` with `-32602`.
- **Server-side logs reach the client** as `notifications/message`, gated by `logging/setLevel`, and `resources/subscribe` resolves for `paleobiology://taxon/{taxon_no}` and `paleobiology://occurrence/{occurrence_no}`.
- **`paleobiology_dataframe_drop` registers through `disabledTool()`** while `PALEOBIOLOGY_DATAFRAME_DROP_ENABLED` is off. It stays off `tools/list` as before, but operators now see it on the HTTP landing page with the env var that turns it on.
- **`MCP_SESSION_MODE` is documented as `stateless`** in `.env.example`, matching the pin the `Dockerfile` already carried. The `GET /mcp` status JSON and the HTML landing page report the resolved mode rather than the `auto` default.
- **Bun pins move to `1.4.0`** — `packageManager` and both `Dockerfile` stages; `engines.bun` stays `>=1.3.0`. The build stage is pinned to `$BUILDPLATFORM`, since Bun 1.4.0 aborts under the QEMU emulation a multi-arch build uses for its foreign leg.
- **The production Docker stage installs with `--omit=peer`** and no longer copies `node_modules/@duckdb` from the build stage — `@duckdb/node-api` is a direct dependency, so the target-platform install resolves the correct native binding.
- **Security reports go to `security@caseyjhand.com`.**
- **`tsconfig.json` typechecks `tests/` alongside `src/`**, with emit split into `tsconfig.build.json`. Framework skills, `scripts/`, and the pristine `changelog/template.md` are re-synced from the package.

## Fixed

- **Tool input-validation failures read as flat `path: message` sentences** rather than a serialized `ZodIssue[]` blob, and an unknown tool name rejects with `-32602` instead of resolving an `isError` result.
- **`PBDB_TIMEOUT_MS` bounds the whole PBDB exchange, not just the response headers.** A PBDB response that arrives promptly and then stalls mid-body now aborts with the same `Timeout` error instead of hanging.
- **A stdio server exits when its client hangs up** — stdin EOF runs the same shutdown path a signal runs.
