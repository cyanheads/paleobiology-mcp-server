# 0.3.6 — 2026-09-19

Framework maintenance across thirteen `@cyanheads/mcp-ts-core` releases. No PBDB query behavior changed; the client-visible changes below arrive with `^0.13.6`.

## Changed

- **`@cyanheads/mcp-ts-core` `^0.12.3` → `^0.13.6`.**
- **`sessionMode: 'stateless'` is now declared in `createApp()`** rather than left to the `MCP_SESSION_MODE` schema default (`auto`, which resolves to stateful). `.env.example` sets `MCP_SESSION_MODE=stateless` explicitly so a source run matches the `Dockerfile`'s pin.
- **Every `canvas_id` input uses the framework's `CanvasIdSchema`** instead of a bare `z.string()`. A malformed id is now rejected at argument validation — before the handler runs — on `paleobiology_dataframe_query`, `paleobiology_dataframe_describe`, `paleobiology_dataframe_drop`, and the optional `canvas_id` on `paleobiology_search_occurrences`.
- **`taxon_not_found` and `interval_not_found` are declared `severity: 'info'`.** A name that resolves to nothing is an ordinary lookup answer, not an incident, so it no longer lands in the error stream operators alert on; `missing_selector` and `interval_lookup_unavailable` keep the default severity.
- **`bun >=1.3.0` → `>=1.4.0`** in `engines`.
- **Skills moved from `skills/` to `framework-skills/`**, so a shipped `.claude-plugin`/`.codex-plugin` never hands development skills to an installing agent; adds the `release-pr-review` skill.
- **CI adds `.github/workflows/codeql.yml`** — static analysis on push, pull request, and a weekly schedule.
- **`.github/CODE_OF_CONDUCT.md` and `.github/CONTRIBUTING.md` added**; issue forms assign `cyanheads` and `config.yml` adds a private security-advisory contact link.
- **README restructured** into a Tools/Resources index plus one capability-reference section per tool and resource, naming its filters, paging, and typed errors.
