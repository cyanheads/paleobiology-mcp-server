# 0.6.0 — 2026-11-21

## Added

- **Locality filters** add `state` and `county` to occurrence searches, collection searches, and diversity queries ([#49](https://github.com/cyanheads/paleobiology-mcp-server/issues/49)).
- **Collection lookup** accepts a list of `collection_no` IDs and returns reconstructed coordinates and the model when PBDB supplies them ([#48](https://github.com/cyanheads/paleobiology-mcp-server/issues/48)).
- **Diversity coverage** reports available occurrence counters and the effective `timerule` (`contain`, `major`, or `overlap`) ([#47](https://github.com/cyanheads/paleobiology-mcp-server/issues/47)).
- **DataCanvas** returns the exact DuckDB `engine_type` when available, forwards describe cancellation, and supports constant `range()` and `generate_series()` queries.

## Fixed

- **Taxon status (breaking)** makes `extant` optional in the tool and resource JSON when PBDB omits extinction status. Tool text reports unknown in that case ([#45](https://github.com/cyanheads/paleobiology-mcp-server/issues/45)).
- **Interval bounds** align nine Permian–Triassic intervals with PBDB's international scale snapshot ([#46](https://github.com/cyanheads/paleobiology-mcp-server/issues/46)).
- **Search paging** discloses the requested limit and effective cap even on final and empty pages. `PBDB_CLAMP_LIMITS` defaults on, and the default deployment page cap is 1,000 ([#50](https://github.com/cyanheads/paleobiology-mcp-server/issues/50)).
- **Search text** labels `accepted_no` correctly and surfaces PBDB filter warnings without assuming how rejected selectors affect the results.
- **Desktop bundle** retains executable SDK skill modules and excludes the Vitest cache.
